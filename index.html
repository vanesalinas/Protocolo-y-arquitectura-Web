¿Qué pasa cuando escribís una dirección y apretás Enter?

  1. DNS traduce el nombre a una IP
  2. TCP/TLS arma un canal seguro
  3. El navegador envía una petición HTTP
  4. El servidor devuelve una respuesta HTTP
  5. El navegador dibuja la página
